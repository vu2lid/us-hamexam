Help & About










Getting started


    

  • Select Technician, General, or Extra from the Pool dropdown.
    • 

  • Use Previous and Next to move through questions.
    • 

  • Tap Reveal Now to show the correct answer immediately.
    • 

  • Set a recall timer with Reveal after to hide the answer for 5–60 seconds, or choose Never to keep it hidden.
    • 

  • Use Pause / Resume to stop and restart the recall timer.
    • 








Progress and bookmarks


    

  • Your current position is saved automatically for each pool.
    • 

  • Bookmarks are saved per pool and identified by stable question IDs.
    • 

  • Reset progress clears saved question positions for all pools but does not remove bookmarks.
    • 

  • No account or sign-in is required.
    • 








Current question pools


Question pools are replaced periodically. Use the current pool for your exam date.


    

    


    

    Version and provenance

    Original standalone Technician exam page by Prem (VE6XMX / VU2XMX). Build system, PWA packaging, tests, and additional features were added later. See AUTHORS.md for details.

    Privacy and offline behavior
    

      

    • No account is required.
      • 

    • No analytics, advertising, telemetry, cookies, or API calls.
      • 

    • Progress, bookmarks, and theme are stored only in the browser’s local storage.
      • 

    • Clearing browser or site data removes saved settings.
      • 

    • The app works offline after it has loaded or been installed.
      • 

    

    


    

    Troubleshooting
    

      

    • Apple Files, Mail, and Quick Look may display the HTML file without running JavaScript. On iPhone or iPad, open the hosted PWA URL in Safari instead.
      • 

    • On macOS, open the file in Safari rather than a document preview application.
      • 

    • If the app fails to start, a startup message shows the stage, sanitized page URL, and sanitized error details. When reporting an issue, include that message, your device model, OS version, browser, and whether the app is installed.
